# Case Management Power BI Dashboard
## Project Overview

This project is a Power BI dashboard designed to analyze case management data and provide clear insights into case status, aging, workload distribution, and data quality.

The dashboard demonstrates practical skills in data preparation, data validation, Power BI visualization, filtering, and reporting for operational decision-making.
## Business Purpose

Case management teams need reliable reporting to understand workload, monitor case status, identify aging cases, and review data quality.

This dashboard provides a centralized view of key case management metrics to support operational monitoring and reporting.
## Key Dashboard Features

- Total case volume monitoring
- Open and closed case analysis
- Case aging analysis using aging groups
- Case workload analysis by assigned team
- Case status and priority analysis
- Case distribution by program and region
- Data quality monitoring
- Interactive filters and slicers for case analysis
- Power BI cards, charts, and visual reports
## Data Preparation & Quality

The dataset was prepared using Power Query before building the dashboard.

Key data preparation activities included:

- Reviewing and validating source data
- Assigning appropriate data types
- Creating calculated columns for case aging
- Creating aging groups to categorize cases by age
- Creating an aging group sort column for chronological reporting
- Identifying and monitoring data quality issues
- Preparing the data for Power BI visualization and analysis
## Dashboard Pages

### Page 1 — Case Management Overview
